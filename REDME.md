# Modern Glassmorphism Portfolio

Portfolio web developer modern dengan desain dark theme, efek glassmorphism, dan animasi particle background. Dibuat murni menggunakan HTML, CSS, dan Vanilla JavaScript.

## ✨ Fitur Utama
- 🎨 **Dark Theme & Glassmorphism**: Desain UI premium dengan efek blur dan transparansi.
- 🌌 **Particle Background**: Animasi partikel dinamis menggunakan HTML5 Canvas.
- 📱 **Fully Responsive**: Layout optimal di semua ukuran layar (Mobile & Desktop).
- 🚀 **Scroll Animations**: Efek muncul saat scroll menggunakan Intersection Observer.
- 🔴 **Live Preview**: Komponen iframe unik yang merender versi *live* dari website itu sendiri.

## 🛠️ Teknologi yang Digunakan
- HTML5
- CSS3 (Custom Variables, Flexbox, Grid)
- JavaScript (ES6+, DOM Manipulation)
- [Font Awesome](https://fontawesome.com/) (Icons)
- [Google Fonts - Inter](https://fonts.google.com/specimen/Inter) (Typography)
